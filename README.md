# 文体部部长工作蒸馏

把文体部部长岗位上重复要做的工作，一个个蒸馏成可直接调用的 skill，集中放在这个仓库里，持续更新。

## 已收录的 skill

| skill | 目录 | 用途 |
|---|---|---|
| 发票报销整理与垫付结算 | [`fapiao-baoxiao-kit/`](fapiao-baoxiao-kit/) | 把一批电子发票连同结算表、两张空白财务模板和一份旧说明，整理成一套口径一致、可直接送财务的报销材料，并算出每位垫付人应得的金额。 |
| 羽毛球赛事筹办全流程 | [`badminton-event-playbook/`](badminton-event-playbook/) | 把一场羽毛球赛从策划案、奖品设计、预算上报、报名、定赛制、排赛程秩序册、人员招募排班与计分表，到采购发票、现场执行、报销衔接的完整做法固化成可执行 SOP，产出整套赛事文件包与逐阶段执行清单。 |

## 目录约定

- 每个 skill 一个顶层目录，目录名即 skill 的 `slug`。
- 每个 skill 目录至少含 `SKILL.md`（能力定义）、`README.md`（怎么用）、`usage-notes.md`（使用日志）。
- 细分规则放 `references/`，可执行脚本放 `scripts/`。
- 新增 skill 时，在上表追加一行即可。

## 用法

把某个 skill 目录打包成 zip，上传到支持技能上传的 Agent 平台，即可用触发词唤起。敏感信息（姓名、卡号、学/工号）在技能包里均以占位符或留空处理，由本人填写。
