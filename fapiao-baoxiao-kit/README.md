# 发票报销整理与垫付结算

**这是什么**：把一批电子发票连同结算表、两张空白财务模板和一份旧说明，整理成一套口径一致、可直接送财务的报销材料，并算出每位垫付人应得的金额。解决的是「每办一次活动就要重复填表、写说明、对金额、算谁该拿多少」这件重复活。

**怎么用这份技能**：

1. 上传：把本技能包 zip 上传到您用的 Agent 平台（凡支持技能上传的平台均可）。
2. 装好：平台识别后，它出现在您的技能 / 能力列表里。
3. 唤起：在对话里说触发词就能调起它，例如「整理这批发票填报销表」「算一下每个人垫了多少钱该给谁多少」「写一份报销情况说明」。

**用前准备**：把发票文件、结算表、两张空白财务模板、一份既有说明放到同一目录，并准备好负责人、收款人、学/工号、支付方式、预算条目、活动名称与日期、采购分工等信息。账号、签字等敏感项会留空，由本人填写。

**产出**：已填费用支出汇总表、已填报销单、报销情况说明、垫付结算表各一份，外加一份差异清单。三处合计金额一致，结算表逐人小计相加等于报销总额。

**边界**：不做发票真伪鉴定、不做税务筹划、不替用户签字盖章；预算条目与分摊口径须由用户给定，不自行决定。
