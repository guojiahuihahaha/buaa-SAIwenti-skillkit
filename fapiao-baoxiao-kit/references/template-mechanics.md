# 表格与文档操作要点

## xlsx：整表重建优先于改合并区

模板自带合并单元格分块（如 A3:A8 与 A9:A12 两块）。行数与模板不一致时，反复拆改合并区容易出错。稳妥做法：读取模板的字体、边框、列宽、行高、对齐方式，按实际行数重新画一张表，保留样式、重排合并区与总计行。

- 汇总表：B 列活动信息只在首行写，A3:A(末行)、B3:B(末行) 纵向合并；总计行 A:C 合并，E 列求和。
- 报销单：J 列签字区 J3:J(末行) 合并成一格；合计行、签字行、收款账户行按模板位置补。

## 签名图嵌入

- 手写签名图先去白底转透明 PNG（按灰度计算 alpha，白底透明、笔画保留）。
- 用锚点对象插入，必须显式给图片尺寸（像素转 EMU），否则会按原图像素尺寸输出、偏大。
- 锚定到签字区首行，行内偏移设 0；偏移在导出 PDF 时不按预期比例生效。
- 只在合并区盖一次，不逐行重复。

## 预览核对

- Excel 表：用文档组件把 xlsx 导出为 PDF（固定格式参数 0），再把 PDF 页渲染成 PNG 目视检查。这样与实际打印一致，比自写渲染脚本准。
- 报销说明 docx：用文档组件读页数（统计参数 2），确认落款与正文同页；PDF 渲染成 PNG 看版面。

## 报销说明：沿用模板 + 控制页数

- 以既有说明 docx 为底稿，复制成新文件后逐段替换正文，保留原格式（仿宋类字体、字号、首行缩进 2 字符、行距、两端对齐）。
- 多段替换：先解析文档结构拿到每段的起止位置，再从后往前逐段替换，避免坐标漂移。
- 模板常带文档网格（docGrid），会强制每页固定行数。加内容导致落款溢到第二页时，保留网格、把全文行距改为固定值 22–23 磅，即可压回一页；删网格反而更不稳。
- 每页容量可按「正文行数 + 落款行数」估算；接近上限时先收行距，再考虑精简文字。

## 运行环境

脚本所用第三方库（表格、文档、PDF 处理）在某些托管 Python 里可能缺失。跑脚本前先确认解释器带齐依赖；缺失时换用已装依赖的解释器，或按环境提示改用系统自带组件。脚本本身跨平台，不写死系统专用绝对路径。
