# 字段映射

## 费用支出汇总表（xlsx，一张工作表）

模板标题为「学生工作费用支出汇总表」。表头 9 列，一行一张发票。

| 列 | 表头 | 填写内容 | 来源 |
|---|---|---|---|
| A | 序号 | 1、2、3… 连续 | 顺序生成 |
| B | 活动日期+活动名称 | 日期区间换行 + 活动名换行 + 筹备说明，只在首行填一次并纵向合并 | 用户给定的活动信息 |
| C | 类别 | 奖品 / 物料 / 配送费，按发票项目归类 | 发票项目内容 |
| D | 明细 | 「奖项 品名×数量」换行 +（销售方名称） | 结算表 + 发票销售方 |
| E | 支出金额 | 价税合计（小写） | 发票 |
| F | 负责人 | 同一人，逐行填 | 用户给定 |
| G | 支付方式 | 如银行卡转账，逐行填 | 用户给定 |
| H | 收款人 | 同一人，逐行填 | 用户给定 |
| I | 备注 | 发票号码（20 位） | 发票 |

末行 A 列写「总计」，E 列为对全部明细行E列求和的公式。原空白模板的合并区按行数重建，不保留模板自带的 6 行 / 4 行分块。

## 报销单（xlsx，一张工作表）

模板标题含「报销单（预算条目：…）」，预算条目须与用户选定项一致，标题、对应列同步改。表头 12 列，一行一张发票。

| 列 | 表头 | 填写内容 |
|---|---|---|
| A | 序号 | 1、2、3… |
| B | 提交日期 | 用户给定的提交日期，逐行填 |
| C | 金额（元） | 价税合计（小写） |
| D | 内容摘要 | 「活动名：奖项 品名×数量」换行 +「发票号…」；不写商家名 |
| E | （与 D 合并） | — |
| F | 收款人 | 同一人 |
| G | 学/工号 | 用户给定 |
| H | 支付方式 | 用户给定 |
| I | 预算条目 | 按活动性质选定 |
| J | 申请人签字（手签） | 多行合并成一区，盖一次透明签名图 |
| K | 经费号（学院填写） | 留空 |
| L | 财务凭证号（学院填写） | 留空 |

合计行：A 列写「合计金额」，C 列对明细行求和；F 列写「研究院编号：」留空。倒数第二行「主管领导签字：」「经费负责人签字：」留空。末行补「收款账户：…　支付方式：…　银行卡号：…」。

## 报销情况说明（docx）

沿用既有说明的公文格式，逐段替换文字，不动样式。段落骨架见 statement-doc.md。

## 垫付结算表（xlsx）

| 列 | 表头 | 填写内容 |
|---|---|---|
| A | 垫付人 | 采购分工代号或姓名 |
| B | 采购项目 | 该人经办的物品与数量 |
| C | 发票张数 | 归集到该人的发票计数 |
| D | 垫付金额（元） | 该人发票价税合计小计 |
| E | 占比 | 该人金额 ÷ 报销总额 |

末行合计等于报销总额、占比合计为 100%。另起一行写「人均应摊 = 合计 ÷ 人数」，人数由用户给定。
