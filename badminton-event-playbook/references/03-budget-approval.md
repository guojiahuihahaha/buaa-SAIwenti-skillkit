# 阶段三 · 预算编制与上报

## 目标
把阶段二的奖品方案变成一份可上报的预算表：逐项算价、汇总总额、落实分工，供审批。这是独立的"写预算、报上去"流程。

## 编制步骤
1. 取阶段二《奖品方案设计表》的每一档奖品、数量、参考单价。
2. 逐项计算 `总价 = 数量 × 单价`，组合奖按拆分后的实际单价分别计算。
3. 每项标注采购分工代号（与设计表一致，便于后续对账）。
4. 表尾汇总总预算金额。
5. 附上采购链接/渠道与注意事项，作为上报附件依据。

## 预算表结构（上报版）
列头：`奖项等级 | 奖品名称 | 数量 | 单价(元) | 总价(元) | 分工代号 | 备注/链接`
- 金额统一保留两位小数。
- 组合奖（如毛巾+护腕）按两件分别列单价并注明，总价合并或分列均可，但要能对账。
- 参与奖若为自有库存，单价/总价填 0 并写"无需购买"。
- 应急药品等按套列的项，注明包含明细与数量。

## 上报要点
- 预算总额是审批与后续报销的对照基准，一经上报即为"预算金额"，赛后结算要与之对比算节余/超支。
- 上报前复核：数量×单价是否算对、组合奖是否漏项、分工是否每条都有人。
- 若审批要求压缩总额，回阶段二调整选品（降档/减量），再重编预算，不直接改数字。

## 判定
- 每项金额正确、合计无误、分工落实、组合奖无漏项 = 合格，可上报。
- 金额算错、合计不符、有项无分工 = 不合格，回本阶段修正。

## 输出
一份上报用《奖品/活动预算表》+ 总预算金额（作为阶段八结算的对照基准）。
