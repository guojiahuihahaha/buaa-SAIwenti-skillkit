# 阶段二 · 奖品方案设计（定买什么）

## 目标
在预算之前，先把"奖要给谁、给什么、给多少"设计清楚。这是独立的策划决策，先定方案再谈钱。输出的《奖品方案设计表》是阶段三编制预算的依据。

## 设计五问（依次回答）
1. **奖项有哪些档位？** 按名次分：金/银/铜奖 + 赛事参与奖 + 纪念品/奖牌 + 横幅 + 应急物资。问清是否给所有参赛者都有参与奖。
2. **每档发什么、什么规格？** 选品原则：与运动场景相关、实用、单价可控、易采购、能开发票。示例：金奖=蒸球器、银奖=运动毛巾+护腕（组合奖）、铜奖=羽毛球手胶、参与奖=马克杯（可自有库存无需购买）、奖牌=金属金银铜。
3. **每档多少份？** 数量 = 获奖队伍数 × 每队上场主力人数（示例：每档 7 份、奖牌 21 个、参与奖 28 个）。留出 2-3 套备用。
4. **谁负责买？** 每个奖项/物资指定一个采购分工代号，组合奖拆成多个链接/多个采购来源时要写清。
5. **有什么采购注意？** 需开发票的渠道提前标出；预算不卡死的项标"差不多即可"；易超支项（如横幅按实际米数）预留浮动。

## 奖品方案设计表结构
列头：`奖项等级 | 奖品名称 | 数量 | 参考单价 | 分工代号 | 采购链接/渠道 | 注意事项`

- 组合奖（一个奖项含多件）分行写或在一格注明"两件、两个链接"，避免漏买。
- 每档注明数量来源（按几支队、每队几人算出来的），便于复核。
- 「注意事项」列写清开发票要求、可替换渠道、浮动容忍度。

## 判定
- 五问全部有答案、每档有明确奖品与数量、每笔有采购分工、组合奖已拆清 = 合格。
- 只有"买点奖品"这种模糊描述、数量无依据、组合奖漏件 = 不合格，回本阶段细化。

## 输出
一份《奖品方案设计表》，交阶段三据此编制预算。
