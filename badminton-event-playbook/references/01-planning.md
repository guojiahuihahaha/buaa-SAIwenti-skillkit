# 阶段一 · 立项与策划案

## 目标
把一场羽球赛的顶层设计一次性写清楚，作为后续所有阶段的依据。一份策划案定稿后，赛程、赛制、人员、预算都从它推导。

## 策划案固定六块结构

1. **活动基本信息**
   - 活动主题（一句话口号 + 全称）
   - 活动目的（丰富文体生活、搭建交流平台、展现精神风貌等，按 actual 填写）
   - 参与对象（全体学生 / 某学院 / 某年级）
   - 赛事安排（比赛日期、场地、分几个组别/时段）

2. **赛事流程**（四段式，每段写清动作）
   - 报名阶段：报名方式（线上问卷）、需收字段、组队规则（如本科按年级、研究生按中心）、截止时间
   - 赛前准备（活动前 N 天）：物资采购清单、场地布置、赛程抽签、志愿者招募
   - 比赛当天流程：工作人员到位、选手实名签到、依规则比赛
   - 赛后工作：现场清理、宣传总结（24 小时内推文 + 反馈收集 + 活动总结）

3. **比赛规则**
   - 团体赛项目与出场规范（单项顺序、出场资格限制）
   - 计分规则（不同阶段分制、是否延分）

4. **赛制设置与晋级规则**（详见 05-format-rules.md）
   - 小组赛阶段：循环赛、积分与排名口径、晋级名额
   - 淘汰赛阶段：对阵产生方式、轮次、胜负判定

5. **通用判罚原则**
   - 迟到/缺席判负口径
   - 争议判罚归属（当值主裁现场判定为最终结果）

6. **应急预案**（详见 09-event-day.md）
   - 突发医疗（轻微/严重分级处置 + 急救电话占位）
   - 赛程调整（弃权处理）
   - 物资短缺（备用 + 紧急采购）

## 物资清单基线（可按规模增减）
- 消耗品：羽毛球（按每场地 2-3 桶）、饮用水
- 器材：记分牌、哨子、球网（校准高度）
- 医疗：急救包（创可贴、云南白药、碘伏棉签、医用冰袋）
- 荣誉：获奖证书、奖牌、奖品
- 场地：横幅、签到台、场地/候场区标识、白板

## 人员基线
- 策划案原计划常偏大（如 17 人全天）；实际招人困难时用半天班制压缩（详见 07-staffing-scoring.md）。策划阶段先列满编，排班阶段再按可用人力降档。

## 判定
- 六块内容齐全 = 合格策划案。
- 缺「时间账」或「报名队伍数未定」就写死赛制 = 不合格，赛制留到阶段五按实际队数定。

## 输出
一份《XX 羽毛球赛策划案》，文末署主办单位与日期。
