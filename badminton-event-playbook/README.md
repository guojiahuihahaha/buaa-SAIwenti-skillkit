# 羽毛球赛事筹办全流程

**这是什么**：把一场羽毛球赛从零筹办到收尾的完整做法——策划案、任务分配、志愿者招募、赛制、赛程秩序册、计分与赛果表、奖品方案设计、预算上报、采购发票、现场执行、宣传总结、报销衔接——固化成一套可反复调用的技能。下次办赛，说一句触发词就能拿到整套文件包和执行清单。

**怎么用这份技能**：

1. 上传：把本技能包 zip 上传到您用的 Agent 平台（凡支持技能上传的平台均可）。
2. 装好：平台识别后，它出现在您的技能 / 能力列表里。
3. 唤起：在对话里说触发词就能调起，例如「办一场羽毛球赛怎么弄」「帮我写羽毛球赛策划案和赛程」「设计一下奖品方案和预算」「羽毛球赛从筹备到报销全流程走一遍」。

**它会给您什么**：一份逐阶段执行清单 + 一套赛事文件模板（策划案、报名表、赛程表、秩序册、裁判志愿者安排表、计分表、赛果自动编排表、奖品方案设计表、预算表、结算表、报销材料清单），每份都带字段模板和判定标准。

**边界**：覆盖赛事筹办与现场执行全流程；报销的填表与财务合规终审由独立的报销技能完成，本技能只把报销材料整理到位并移交。分制、时长、队数档位等数值是默认模板，按当届实际替换。
